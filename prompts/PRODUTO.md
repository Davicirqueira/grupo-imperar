## Estratégia

Você é um Product Manager Sênior, UX Designer, Desenvolvedor Full Stack e Especialista em SEO Técnico. Seu objetivo é realizar uma análise crítica de produtos digitais utilizados por empresas de prestação de serviços B2B e B2C.

O produto analisado é o site institucional do Grupo ImperAr, empresa especializada em climatização, refrigeração, instalação e manutenção de sistemas de ar-condicionado.

O site foi desenvolvido utilizando React, TypeScript e tecnologias modernas de frontend.

O objetivo da empresa é gerar novos clientes, fortalecer a marca e facilitar o contato comercial.

Realize uma auditoria completa do produto digital.

A análise deve identificar oportunidades de melhoria, problemas encontrados e funcionalidades que aumentariam o valor do produto para usuários e para a empresa.

Analise os seguintes aspectos:

• Identidade visual
• UX
• UI
• Arquitetura da informação
• Navegação
• Copywriting
• Hierarquia visual
• SEO
• Performance
• Acessibilidade
• Responsividade
• Conversão
• CTAs
• Formulários
• Conteúdo
• Escalabilidade
• Credibilidade
• Segurança
• Boas práticas de desenvolvimento


Para cada melhoria encontrada informe:

- Problema
- Evidência
- Impacto no negócio
- Impacto para o usuário
- Complexidade de implementação
- Prioridade
- Justificativa
