## STACK TECNOLÓGICA

Stack Tecnológica
Frontend:

HTML puro (sem frameworks)
CSS puro (sem preprocessadores ou frameworks)
JavaScript puro (vanilla JS, sem frameworks ou bibliotecas)
Tipografia:

Barlow - para títulos e headings
Inter - para corpo de texto
Paleta de Cores:

Azul céu: #3AAEDC (cor principal)
Azul profundo: #1A2B5C (cor secundária)
Azul médio: #2490BA (hover states)
Azul claro: #E8F7FD (backgrounds)
Azul escuro: #0F6080 (acentos)
Cinza claro: #F4F6F8 (backgrounds alternativos)
Cinza escuro: #4A4A4A (texto)
Branco: #FFFFFF
Estrutura:

Sistema de espaçamento baseado em múltiplos de 8px (8px, 16px, 24px, 32px, 48px, 64px)
Design responsivo com breakpoints: mobile (<768px), tablet (768px-1024px), desktop (≥1024px)
Arquitetura de arquivos separados: HTML, CSS e JS em arquivos distintos
A abordagem é sem frameworks, priorizando código nativo e performance.
